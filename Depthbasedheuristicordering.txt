Depth-based heuristic weighting

Use different weights depending on how many plies remain in this search: 
H = 2(Sm−So) + (Bm−Bo) when remaining depth > 1, and H = 5(Sm−So) + 3(Bm−Bo) right at the horizon (remaining depth = 1).

def heuristic_depth_based(state, player, remaining_depth):
    opp = 1 - player
    Sm, So = state.store[player], state.store[opp]
    Bm, Bo = sum(state.side[player]), sum(state.side[opp])
    if remaining_depth > 1:
        return 2 * (Sm - So) + 1 * (Bm - Bo)
    else:
        return 5 * (Sm - So) + 3 * (Bm - Bo)
